# Accessing Admin Backend to Add / Edit Blogs & Projects

Anyone who can write to the repo can log into /admin and edit content.

**Add someone as a collaborator (most common)**

Steps:

1. Go to your repo on GitHub:
2. Click Settings
3. Click Collaborators
4. Click Add people
5. Enter their GitHub username or email
6. Choose permission level:
    ✅ Write → can edit content via Decap
    ❌ Read → cannot log in
    ⚠️ Admin → only if they should manage repo settings

Once they accept the invite:
- They go to /admin
- Click Login with GitHub
- They’re in 🎉
